# Reg GA Signing — Persisted State Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Regulation of the General Assembly (Reg GA) signing persist to document state like the other three signable documents, fixing the always-pending sidebar entry.

**Architecture:** Fold Reg GA into the existing `Stage2DocumentType` pattern — add a `REG_GA` enum value and a `regGaDocument` state field, route it through the existing `SET_STAGE2_DOCUMENT_MARKDOWN` / `MARK_STAGE2_DOCUMENT_SIGNED` operations, replace the bespoke `StepRegulationGA` UI with the shared `Stage2DocumentStep` wrapper, and wire the sidebar to real state. No new operations.

**Tech Stack:** Powerhouse document model (GraphQL schema + reducers), reactor-mcp for model edits, React + TypeScript editor, Vitest for reducer tests.

**Branch:** `feat/reg-ga-signing-state` (already created; spec already committed there).

**Key context for the implementer:**
- The reactor-mcp server must be running (`ph vetra`) and connected. The SwissAssociation **document-model document id is `8d6de322-94fe-40b0-8eed-5c4802527424`** on drive `vetra-16dda929`.
- **The MCP-stored reducer has diverged from `src/`.** The model stores an inline ternary; `src/reducers/documents.ts` uses a `getTargetDocument` helper. The runtime uses `src/` (codegen does NOT overwrite `src/`). So you must update **both**: `src/` for runtime behavior, and the MCP model so future codegen stays correct.
- Editing the model via `addActions` triggers Vetra codegen, which regenerates `document-models/swiss-association/v1/schema.graphql` and `gen/`. If it does not auto-run, run `npm run generate` (see README).

  dispatch: DocumentDispatch<SwissAssociationAction>;
  onBack: () => void;
  onNext: () => void;
}

export function StepRegulationGA({ state, dispatch, onBack, onNext }: Props) {
  return (
    <Stage2DocumentStep
      title="Regulation of the General Assembly"
      description="Review the Regulation of the General Assembly — the decision-making rules governing how your association votes and operates. The template has been populated with your association's data. Please review and sign if you agree."
      documentType="REG_GA"
      dispatch={dispatch}
      documentState={state.regGaDocument}
      generateMarkdown={() => buildRegulationGAMarkdown(state)}
      onBack={onBack}
      onNext={onNext}
      nextLabel="Continue →"
      nextRequiresSigned={true}
      lockedHint="The Regulation of the General Assembly is now locked and cannot be edited."
    />
  );
}
